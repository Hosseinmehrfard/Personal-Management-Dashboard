# پنل مدیریت شخصی | Personal Management Dashboard

وب‌اپ فارسی و راست‌به‌چپ برای مدیریت مستقل وظایف، سرورها، امور مالی، دارایی‌ها و کلاس‌های آموزشی. ساخته‌شده با React، Node.js/Express، PostgreSQL و PWA؛ قابل اجرا با Docker Compose و HTTPS از طریق Caddy.

**نسخه: 6.2.0** — توسعه‌یافته بر پایه ۵.۲ با حفظ داده‌ها و اتصال‌های NerkhAra، ارزدیجیتال و نوسان.

## قابلیت‌ها

- **داشبورد:** کارهای باز، ارزش پس‌انداز به تومان، هزینه ماه جاری، وضعیت کلاس‌ها، موارد بازبینی و فعالیت‌ها.
- **کاربران مستقل:** مدیر اصلی حساب‌های عادی می‌سازد، رمز آنها را بازنشانی یا حساب را غیرفعال می‌کند. سرورها، وظایف، پس‌انداز، تراکنش‌ها، کلاس‌ها، مباحث، منابع و فعالیت‌های هر کاربر با `user_id` در PostgreSQL جدا می‌شوند. کاربر عادی به APIهای مدیریت سراسری دسترسی ندارد.
- **آپدیت بدون ورود مجدد به SSH:** پس از **راه‌اندازی اولیه انتشار**، مدیر می‌تواند workflow ثابت GitHub Actions را از داخل پنل اجرا و وضعیت را بررسی کند. هیچ Docker socket یا کلید SSH به خود برنامه وب متصل نمی‌شود.
- **ارزها:** مشاهده و تعیین نمایش/عدم نمایش مستقل برای هر کاربر. افزودن و ویرایش انواع ارز و نماد توسط مدیر؛ نرخ‌ها از NerkhAra، ارزدیجیتال یا نوسان؛ ارزش همه دارایی‌ها به تومان.
- **مالی و پس‌انداز:** درآمد و هزینه، اقساط، پس‌انداز تومانی یا دلاری/تتری/یورویی/طلا و ... با پیش‌نمایش ارزش تومانی.
- **کلاس‌ها:** ایجاد کلاس دلخواه، فصل، مبحث، یادداشت، منبع و پیوند قابل راستی‌آزمایی، کارهای مرتبط و وضعیت پیشرفت. محتوای OWASP قدیمی هنگام مهاجرت زیر یک کلاس نگهداری می‌شود.
- **تقویم هجری شمسی:** ماه‌نما برای کارها و سررسید اقساط؛ انتخابگر تاریخ شمسی در فرم‌ها. تاریخ‌های ذخیره‌شده در SQL مطابق ISO/Gregorian باقی می‌مانند.
- **PWA:** نصب از مرورگر روی موبایل و دسکتاپ؛ داده‌های خصوصی در کش آفلاین ذخیره نمی‌شوند.

## فناوری‌ها

| لایه | فناوری |
|---|---|
| Frontend | React 19 + Vite + RTL |
| Backend | Node.js 22 + Express |
| Database | PostgreSQL 17، جداول رابطه‌ای |
| Deployment | Docker Compose + Caddy/HTTPS |
| Password | scrypt-v2، نشست HttpOnly و محافظت CSRF |
| Market data | NerkhAra / ArzDigital / NavAsan |

## نصب تازه

Ubuntu/Debian، یک دامنه با DNS صحیح و پورت‌های ۸۰ و ۴۴۳ لازم است. پس از آپلود فایل‌های این مخزن روی GitHub:

```bash
curl -fsSL https://raw.githubusercontent.com/Hosseinmehrfard/Personal-Management-Dashboard/main/install.sh | sudo bash -s -- https://github.com/Hosseinmehrfard/Personal-Management-Dashboard.git dashboard.example.com
```

`dashboard.example.com` را با دامنه واقعی جایگزین کنید. کد راه‌اندازی نخستین مدیر هنگام نصب ایجاد می‌شود؛ آن را عمومی نکنید. اطلاعات در Volume پایدار `markaz_pg_data` ذخیره می‌شوند. **نام داخلی Compose عمداً `markaz` باقی مانده است تا دیتابیس نسخه‌های قبلی گم نشود.**

## ارتقا از نسخه ۵.۲

ابتدا آخرین کد نسخه ۶ را در شاخه `main` مخزن قرار بدهید. سپس برای این نوبت، از طریق SSH:

```bash
cd /opt/markaz && sudo bash backup-db.sh && sudo git pull --ff-only origin main && sudo docker compose --profile https up -d --build --remove-orphans && sudo docker compose ps
```

**مهم:** قبل از ارتقا فایل dump دیتابیس را خارج از سرور نیز نگهداری کنید. `docker compose down -v` یا حذف `pg_data` ممنوع است. Migration ۵ داده‌های قبلی را به مالک اصلی منتسب می‌کند و فصل‌های OWASP قبلی را زیر کلاس «OWASP Top 10:2025» حفظ می‌کند. حساب مدیر و `.env` قبلی حفظ می‌شوند.

## فعال‌سازی «آپدیت از پنل»

راه‌اندازی اولیه لازم است و با صرفاً نصب نسخه ۶، مجوز انتشار خودکار ایجاد نمی‌شود. فایل [WEB-UPDATES-fa.md](WEB-UPDATES-fa.md) شامل ساخت کلید جداگانه، نصب عامل حداقلی به‌روزرسانی، تنظیم GitHub Environment Secrets و PAT با مجوز محدود است.

پس از تنظیم اولیه، در **مدیر سیستم ← آپدیت برنامه** نام مخزن `Hosseinmehrfard/Personal-Management-Dashboard` و توکن GitHub Actions را ذخیره کنید. دکمهٔ «شروع آپدیت از GitHub» workflow `deploy.yml` را برای شاخه `main` اجرا می‌کند. برنامه نتیجه اجرای workflow را نشان می‌دهد؛ موفقیت نهایی از گزارش Action و سلامت سایت مشخص می‌شود.

## استفاده از کاربران

مدیر اولیه در صفحهٔ راه‌اندازی با `SETUP_TOKEN` ساخته می‌شود. در منوی **مدیریت کاربران**، برای هر کاربر نام کاربری و رمز حداقل ۱۲ نویسه تعریف کنید. کاربر وارد پنل اختصاصی خود می‌شود و داده‌های دیگران را دریافت نمی‌کند. نرخ‌های مرجع ارز و تنظیمات سرویس API سراسری هستند؛ فقط مدیر اصلی آنها را تغییر می‌دهد.

## پشتیبان و امنیت

```bash
cd /opt/markaz && sudo bash backup-db.sh
```

کلیدهای API در سرور رمزگذاری می‌شوند و در پاسخ تنظیمات یا خروجی JSON نمایش داده نمی‌شوند. درخواست‌های تغییردهنده از نشست HttpOnly، اعتبارسنجی مبدأ و CSRF استفاده می‌کنند؛ داده‌های SQL با پارامترهای جدا ارسال می‌شوند؛ مسیرهای عمومی نرخ‌گیری به هاست‌های مشخص محدود شده‌اند. حذف حساب کاربر فعلاً فعال نیست تا داده‌های او سهواً از بین نرود؛ غیرفعال‌سازی و بازنشانی رمز پشتیبانی می‌شوند.

## آزمون

```bash
npm install
npm run check
npm run build
npm run secrets:scan
npm audit --audit-level=high
```

مخزن هنوز فاقد `package-lock.json` است؛ در نخستین نصب دارای دسترسی به npm registry باید تولید و Commit شود. اجرای تست‌ها و Build و مهاجرت واقعی دیتابیس روی سرور هدف برای تأیید انتشار لازم است.
